## 📌 About This Repository

This repository tracks daily progress, code experiments, and functional projects built while advancing through modern React. Each day focuses on a distinct architectural concept paired with a standalone, runnable mini-project.

### Key Goals
- Build and push working code to GitHub every single day.
- Learn React fundamentals, state management, hooks, and routing through hands-on practice.
- Adhere to clean folder architecture, semantic code, and conventional Git commit habits.
